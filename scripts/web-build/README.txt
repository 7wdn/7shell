7Shell 浏览器版（Linux x86_64）
================================

这是给没有 WebKitGTK 4.1 / 新版 glibc 的系统（UOS 20、Deepin、麒麟等）准备的运行方式：
本机只跑一个本地服务，界面在系统自带的浏览器里打开。不需要 root，不需要安装依赖，不需要 WebKit。

要求
----
- x86_64 Linux，glibc 2.28 或更高
- UOS 自带浏览器、奇安信浏览器、Chrome、Edge、Firefox 都可以（已针对旧版 Chromium 做了颜色回退）
- 需要 SSH / SFTP 时，目标主机网络可达


运行
----
在文件管理器里双击 “7Shell” 图标（选择“在终端中运行”），或者在终端里：

    cd 解压后的目录
    ./7shell

启动后会自动打开浏览器；没有自动打开时，把终端里打印的地址
（形如 http://127.0.0.1:4225/?token=...）粘贴到浏览器地址栏。

按 Ctrl+C 停止服务。界面关闭不影响服务，重新打开上面的地址即可。

如果解压工具没有保留可执行权限：

    chmod +x 7shell bin/sevenshell-web


数据
----
配置、保险库、已知主机和命令历史都保存在本目录的 data/ 下。
想换位置就设置环境变量：

    SEVENSHELL_CONFIG_DIR=/home/你/7shell-data ./7shell

端口默认 4225；被占用时启动脚本会自动往后找。也可以指定：

    SEVENSHELL_WEB_PORT=4300 ./7shell


这个版本能做什么
----------------
- SSH 终端：跳板机、本地端口转发、agent forwarding、终端配色与查找、会话录制
- 会话与分组、已知主机校验、密钥管理、导入/导出
- SFTP：浏览、新建、改名、权限、文本编辑、上传/下载到本机、打包下载
- 命令库、跨所有终端的共享命令历史、补全
- 主机监控、批量执行（带风险分级、策略矩阵与审计）
- AI 助手（Anthropic / OpenAI 兼容 / 本地模型），工具调用走同一套审批与审计
- MCP：接入外部服务器（含 OAuth、资源、提示词），也提供本地监听器与桥（bin/sshell-mcp）
- 容器（Docker / Podman / nerdctl / WSLC）与 Kubernetes 工作区、容器与 Pod 文件
- 同步（WebDAV、GitHub / Gitee / GitLab 片段）、终端里的 ZMODEM 收/发


这个版本还没有
--------------
- 远程桌面（RDP）与自动更新：桌面版专属
- WSL 会话：只在 Windows 宿主上有
- arm64 的浏览器包：当前只提供 x86_64


安全说明
--------
服务只绑定 127.0.0.1，并且每次启动生成新的访问令牌；令牌在页面地址里。
不要把带 token 的地址发给别人，也不要把端口转发到公网。
